# 星图仪 · Astral Atlas 1.7.0 — 内轨

适用于 Folia >=0.7.28 <0.8.0，使用 Folium 的公开客户端接口。单一浑天仪场景，依照用户提供的 `astral-inside-orbit-demo.mp4` 重新制作。预览由本包实际渲染器录制。

## 安装和升级

1. 在 Folia「设置 → 模组」开启模组系统。
2. 将 `astral-atlas-1.7.0.zip` 原样导入模组面板；旧版使用相同的 `astral-atlas` id，先停用旧版再更新。
3. 确认版本为 1.7.0，启用，并完成 Folia 的原生确认。
4. 在歌词动画选择器选择「星图仪 · 内轨」。

此包未获得 Folium 官方签名，宿主显示「未验证」是预期行为。没有 main 入口、额外权限、网络请求、内置音乐、内置参考视频或第三方字体。旧版 ZIP 仍保留在项目 releases 目录。

## 这一版的画面

- 单场景：从浑天仪整体连续推入内部；约 1.55 秒进入内轨视角。正常换句不重置镜头，不再轮换旧版五种场景或歌词构图。
- 深蓝黑背景、低亮度黄铜环带、细刻度、罗马数字、内层星座网、中心星芒与边侧星盘。白天使用浅纸色与深色墨线。
- 歌词在上下两条星轨交替出现，出场句短暂留在原轨淡出。每个字的基线使用所属环带的三维位置、刻度旋转相位与透视投影，沿轨道弯曲、转动与移动。
- 四周频谱改为细小光点和极少量微小横向光痕，移除向外生长的短针与十字闪烁。相邻 FFT 分箱先加权平均，再以约 100ms 起动、380ms 回落的包络平滑亮度与微小尺寸变化。只有频段输入时使用对应频段；固定分布，不伪造节拍，静音平滑回落。文字区域减弱星点亮度。
- 环形白点频谱默认减疏为 64 点，缩小点径，可见度降为原来的 65%，避免白点环过于突出；「白点数量」和「白点可见度」可继续单独调节。白点围绕内层星仪排列，按对应频段向外弹起，平滑回落；没有放射短针。独立使用约 45ms 起动、220ms 回落的频谱包络，并响应真实低频瞬态。静音时回到基础点环，不伪造跳动。它与散落星尘分别开关；即使星轨运动幅度设为 0，音乐仍可推动白点。系统减少动态效果、静态预览或音乐响应为 0 时停止弹跳。
- 主歌词按歌词时钟逐个字形簇从无到有显现，未唱到的字完全不绘制，不再提前显示灰色整句。整句的位置和各字字距预先固定，出现新字时不会重新居中。字词时间决定显现顺序，音频能量控制显现后字形的呼吸；没有从音频波形自动识别歌词内容。
- 1.7 原版内修正：单字淡入延长为约 180–260ms，相邻字的过渡可自然重叠；取消主句入场时重复叠加的淡入，减轻字形伸缩并延长回落。复用同帧旋转计算，跳过画面外的线段和环带，减少逐字显现时的慢帧。版本号保持 1.7.0，更新同名安装包。
- 「歌词浮现速度」可在 0.4–2 之间独立调节，默认 1 保持当前柔和过渡；低值放慢单字淡入，高值加快。只改变显现过程，不改变字词与歌曲的同步时点，也不影响星轨移动速度。暂停时调节可即时预览，静态模式始终显示完整句。
- 按原始 8 秒参考校正移动方向和速度：上轨歌词向左，下轨歌词向右。默认在 1280×720 内轨视角约每秒移动 30 余像素，具体随曲率与透视变化。「歌词随轨移动速度」独立调节，1 为参考速度，0 停止沿轨传送；字词显现时间不受速度滑块影响。超长句缓慢巡行，避免整句尚未唱完就移出画面；传送时钟跨句连续。
- 关键词使用较大字形，助词和标点缩小，形成视频中的大小层次。关键词按分词、长度及实际延音时长选择，属于排版规则，不是语义识别。有真实逐词时间时，整词随低频、人声频段轻微展开和回落；唱到的字逐渐染金。慢速天体运行与音乐响应分开。
- 译文改为完整一句排在主轨下方留白处，跟随主句锚点移动，保留小幅切线倾斜；不再逐字绕弧挤到主句旁。边界限制防止译文进入页脚。字号和与主句的间距独立可调。
- 页眉歌曲名、歌词与译文读取当前 Folia 播放数据，未固定为参考视频中的歌曲。底部自绘的歌曲信息、时间和进度条已移除，使用 Folia 自带的播放控制区。

## 设置

「浑天仪大小」「随轨歌词大小」「译文大小」「译文与主句间距」「刻度标注大小」「白点环大小」独立可调。「环形白点频谱」默认开启，可单独调整「白点跳动幅度」。还可调歌词随轨速度、星轨运动、音乐响应、字形律动、星尘密度、星点频谱开关及幅度、天文标注、透明背景和音频状态。歌词大小同时尊重 Folia 的文字缩放；过长句会自动压缩字号以容纳在可见弧段，较长文本建议适当减小字号。

日夜配色默认跟随 Folia 的太阳 / 月亮切换；也可固定白天、夜晚或使用自定义颜色。暂停时修改配色和尺寸立即生效。升级会保留相同设置键的旧值；若旧版调整过尺寸、配色或强度，可手动设回：图形/歌词/标注 = 1，运动/响应/字形 = 1，星尘 = 0.65，配色 = 跟随 Folia。

隐藏歌词同时隐藏所有主句和译文；译文/音译、字幕透明度跟随宿主。透明输出时自动省略底色。静态预览冻结星仪并显示完整指定句；系统减少动态效果时冻结持续运动与字形伸缩，保留按时间染色。暂停与宿主保持画面状态时停止逐帧绘制。非宽屏比例采用居中等比构图，避免把圆环拉扁。

## 音频来源

直接从 Folia 每个共享渲染帧读取 FFT / 五频段和音量，不使用麦克风或另开播放流。有逐词时间时保留其时间和词间停顿；逐行 LRC 只能按行时长均匀分配，无法恢复真实逐字时间。

Folia 0.7.28 的部分 HiFi / mpv 或外部播放路径不会提供真实 FFT，而会返回五频段与音量完全相同的占位呼吸。本模组识别这种值并抑制，避免把它当作音乐节拍。如有问题，打开「显示音频信号状态」：`FFT` 表示频谱，`BANDS` 表示频段，`SILENT` 表示静音，`NO FFT` 表示宿主没有提供可用分析。此时请在 Folia 中使用能提供分析的普通内置播放路径；模组无法补出宿主未提供的音频数据。

已使用 Folia v0.7.28 官方文件检查器、独立 Electron Folium 上下文测试及真实 Web Audio FFT 录制验证。测试包含三维歌词附着、长歌曲时间范围、Unicode 计时、暂停拖动、日夜/透明/隐藏文字、独立尺寸和清理订阅。预览使用原创演示文字及合成测试音频，不含人声。未在用户当前运行的 Folia 实例内代为导入或启用。
